Supplementary online-only material for
"Beyond Storage: State as a Runtime Control Problem in Parallel and Distributed Systems"

This package contains two LaTeX entry points.

main.tex is the publication manuscript. Its formatted pages, including the
reference list, are the pages intended to count toward the ACM Computing
Surveys 35-page limit for a Long Survey Paper.

supplement.tex is electronic supplementary material. It provides literature
boundary context, design checklists, case walkthroughs, and additional domain
figures that support the main manuscript. It is intended to be published
online with the article and is not part of the 35-page publication manuscript.

Both entry points compile with the included ACM authoring-template files in
acmart/. The supplement has no software, data, or runtime requirement beyond a
standard LaTeX installation and the included source files.
